# AI Вёрстка

Программа вёрстки в браузере: публикации, рамки, стили, мастер-страницы,
экспорт в PDF и IDML — с помощником на вашей локальной модели и публикациями на вашем сервере. Ставится
папкой на сервер с nginx и PHP: инструкция — [`studio/README.ru.md`](studio/README.ru.md), что нового —
[`studio/CHANGES.ru.md`](studio/CHANGES.ru.md). Готовые сборки — в Releases.

Основано на [DesignCraft](https://github.com/storytold/designcraft) (MIT OR Apache-2.0); описание исходного
проекта — [`docs/README-upstream.md`](docs/README-upstream.md), лицензии — [`NOTICE`](NOTICE).

InDesign — товарный знак Adobe. AI Вёрстка не связана с Adobe и работает с файлами в её форматах.
